# Video to Learning App

Instantly turn any video—from YouTube, a local file, or a direct camera recording—into a fun, interactive learning app using the power of AI.

## About The Project

This application is a creative experiment that leverages the Google Gemini API to analyze video content and automatically generate a specification for a simple, interactive web-based learning app. It then uses that specification to write the HTML, CSS, and JavaScript code for the app on the fly.

The goal is to provide a tool that can transform passive video consumption into an active, hands-on learning experience.

## Features

- **Multiple Video Sources**:
  - **YouTube**: Paste any YouTube video URL.
  - **Local Upload**: Upload a video file directly from your device.
  - **Camera Recording**: Record a new video using your computer's camera.
- **AI-Powered Generation**: Analyzes video content to create a relevant and educational interactive spec.
- **Automatic Code Creation**: Generates a complete, self-contained HTML file for the learning app.
- **Interactive Preview**:
  - **Render Tab**: See and interact with the live generated app.
  - **Code Tab**: View and edit the generated HTML code in a full-featured editor.
  - **Spec Tab**: Review and even edit the AI-generated specification to regenerate the code with new instructions.
- **Sharing**: Share any app generated from a YouTube URL with a single, shareable link.

## How To Use

1.  **Provide a Video**:
    - Paste a YouTube URL into the input box and click **Generate from URL**.
    - Or, click **Upload Video** to select a file from your computer.
    - Or, click **Use Camera** to record a new video.
2.  **Generate**: The AI will analyze the video and begin generating the learning app. This may take a moment.
3.  **Interact**: Once complete, the generated app will appear in the "Render" tab.
4.  **Explore**:
    - Click the "Code" tab to see the source code.
    - Click the "Spec" tab to see the plan the AI used. You can edit this spec and regenerate the code!
5.  **Share**: If you used a YouTube URL, click the "Share" button to copy a unique link to your generated app.
